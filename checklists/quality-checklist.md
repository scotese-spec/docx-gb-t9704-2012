# 公文质量检查清单（100+项）

> 打印或逐项核对，覆盖格式/内容/用语/逻辑/细节/签发各维度

---

## 第一部分：格式检查 (40+项)

### 1.1 页面设置 (8项)
- [ ] 纸张大小为 A4（210mm × 297mm）
- [ ] 上页边距 37mm（±1mm）
- [ ] 下页边距 35mm
- [ ] 左页边距 28mm（±1mm）
- [ ] 右页边距 26mm
- [ ] 版心尺寸 156mm × 225mm
- [ ] 每面约 22 行、每行 28 字
- [ ] 页边距统一（所有节一致）

### 1.2 字体字号 (10项)
- [ ] 标题：二号（22pt）小标宋体，居中
- [ ] 正文：三号（16pt）仿宋_GB2312
- [ ] 一级标题（"一、"）：三号黑体加粗
- [ ] 二级标题（"（一）"）：三号楷体_GB2312加粗
- [ ] 三级标题（"1."）：三号仿宋_GB2312
- [ ] 主送机关：三号仿宋_GB2312
- [ ] 签发人姓名：三号楷体_GB2312
- [ ] 抄送机关：四号（14pt）仿宋_GB2312
- [ ] 印发机关和日期：四号仿宋_GB2312
- [ ] 无多余字体（不超过4种字体）

### 1.3 行距段落 (8项)
- [ ] 正文行距固定值 28 磅
- [ ] 标题行距固定值 28 磅
- [ ] 正文首行缩进 2 字符（0.74cm）
- [ ] 段落间无多余空行
- [ ] 段落前后间距 ≤ 2pt
- [ ] 主送机关顶格编排
- [ ] 标题与主送机关之间空 1 行
- [ ] 附件说明前空 1 行

### 1.4 版头要素 (6项)
- [ ] 发文机关标志（红头）居中
- [ ] 发文字号在红头下空 2 行居中（上行文居左）
- [ ] 签发人存在（仅上行文）
- [ ] 红色分隔线存在且与版心等宽
- [ ] 密级、份号、紧急程度（如有）标注正确
- [ ] 无多余或缺失版头要素

### 1.5 版记页码 (8项)
- [ ] 抄送机关在版记部
- [ ] 印发机关和日期在末条分隔线之上
- [ ] 版记分隔线与版心等宽
- [ ] 首条分隔线粗线、中间细线
- [ ] 页码用四号半角宋体阿拉伯数字
- [ ] 页码格式" — 1 — "
- [ ] 单页码居右、双页码居左
- [ ] 空白页不编码

---

## 第二部分：内容检查 (30+项)

### 2.1 文种正确性 (6项)
- [ ] 文种选择正确（15种之一）
- [ ] 上行文用请示/报告/议案
- [ ] 下行文用通知/决定/批复
- [ ] 平级文用函
- [ ] 无文种混用（如"请示报告"）
- [ ] 文种与内容匹配

### 2.2 标题 (5项)
- [ ] 标题三要素齐全（发文机关+事由+文种）
- [ ] 事由准确概括全文内容
- [ ] 无书名号或多余标点
- [ ] 长度适中（20-40字）
- [ ] 分行排列对称（梯形或菱形）

### 2.3 主送机关 (4项)
- [ ] 主送机关是单位非个人
- [ ] 请示只写一个主送机关
- [ ] 主送机关名称全称或规范简称
- [ ] 主送机关末尾有全角冒号

### 2.4 正文结构 (8项)
- [ ] 首段写明发文依据（为什么）
- [ ] 中间有具体事项（做什么）
- [ ] 末尾有执行要求（怎么做）
- [ ] 层次结构清晰（一→（一）→1.→（1））
- [ ] 层级无跳跃
- [ ] 每段表达单一意群
- [ ] 无无关内容
- [ ] 关键信息突出

### 2.5 附件与落款 (7项)
- [ ] 附件说明在正文下空一行
- [ ] 附件名称后不加标点
- [ ] 有附件时正文末尾有附件引用
- [ ] 发文机关署名准确
- [ ] 成文日期用阿拉伯数字（2026年5月15日）
- [ ] 无空白印章
- [ ] 印章位置不超出留白

---

## 第三部分：用语检查 (40+项)

### 3.1 准确性 (10项)
- [ ] 无模糊词（大概/也许/差不多）
- [ ] 无歧义表达
- [ ] 数据来源有据
- [ ] 人名、单位名、地名准确
- [ ] 时间节点明确
- [ ] 政策引用完整
- [ ] 因果关系明确
- [ ] 条件关系清晰
- [ ] 定义明确（如需）
- [ ] 范围限定适当

### 3.2 简洁性 (8项)
- [ ] 无冗长表达（如"进行认真的研究讨论"）
- [ ] 无用词重复
- [ ] 无虚词赘语
- [ ] 句式不过长（单句不超过50字）
- [ ] 无不必要的修饰
- [ ] 一意一段
- [ ] 无凑字数现象
- [ ] 无程式化套话

### 3.3 规范性 (12项)
- [ ] 无俚语/口语（搞定/摆平/好多）
- [ ] 无网络用语
- [ ] 称谓规范（主要负责同志 > 一把手）
- [ ] 无情绪化语言
- [ ] 无政治性禁用词
- [ ] 无夸大渲染语（辉煌/无比/极其）
- [ ] 政治表述准确
- [ ] 名词术语规范
- [ ] 发文单位自称一致
- [ ] 引用文件时标注发文字号
- [ ] 涉外用语稳妥
- [ ] 无性别/地区歧视语

### 3.4 结束语 (5项)
- [ ] 请示结束语正确（妥否，请批示）
- [ ] 报告结束语正确（特此报告）
- [ ] 批复结束语正确（此复）
- [ ] 函结束语正确（此函/请予支持为盼）
- [ ] 通知结束语正确（特此通知/请遵照执行）

### 3.5 格式用语 (5项)
- [ ] 发文依据用"根据""为""按照"
- [ ] 过渡句用"现将……如下："
- [ ] 会议要求用"指出/强调/要求/决定/号召"
- [ ] 正文无空泛套话
- [ ] 语气与行文方向匹配

---

## 第四部分：逻辑检查 (10+项)

- [ ] 前因后果无矛盾
- [ ] 时间先后正确
- [ ] 分类并列不交叉
- [ ] 政策引用无倒置
- [ ] 前后表述一致
- [ ] 数据运算正确
- [ ] 条件 → 结果逻辑完整
- [ ] 无法律/制度冲突
- [ ] 权利和义务对应
- [ ] 目标和手段匹配

---

## 第五部分：细节检查 (20+项)

- [ ] 密级标注（如需）
- [ ] 保密期限（如需）
- [ ] 附件数量与实际一致
- [ ] 页码连续
- [ ] 印章与发文机关一致
- [ ] 联系人及电话（请示需有）
- [ ] 起草人/审核人记录（如需）
- [ ] 抄送范围适当
- [ ] 印发日期在成文日期之后
- [ ] 无空白页遗漏处理
- [ ] 装订方向正确（左侧）
- [ ] 页间误差 ≤ 4mm
- [ ] 表格格式规范
- [ ] 所有插入图片清晰可辨
- [ ] 附件文件齐全
- [ ] 紧急程度（如需）标注正确
- [ ] 签发人签名或盖章
- [ ] 发文机关署名无误
- [ ] 无未替换的模板占位符
- [ ] 数字/单位前后一致

## 第六部分：签发前最终确认 (10+项)

- [ ] 发文机关主要负责人已审签
- [ ] 内容已经多部门确认（如涉多部门）
- [ ] 政策法规部门已会签（如涉政策）
- [ ] 附件内容已与正文核对
- [ ] 分发范围已明确
- [ ] 文件编号已确认
- [ ] 是否有前任审批
- [ ] 印刷份数已定
- [ ] 日期已确认为签发日期
- [ ] 最终稿与签发稿一致

五楷体二级黑体一，
六是否全文无英文半角；
七有没有请示混了报告，
八日期年月日标全数字。
