# 公文类型写作指南（15种）

> 依据：中办发〔2012〕14号《党政机关公文处理工作条例》
> 配套模板：`../templates/` 目录下对应 .md 模板

---

## 文种分类总览

| 分类 | 文种 | 方向 |
|------|------|------|
| 上行文 | 报告、请示、议案 | 下级 → 上级 |
| 下行文 | 通知、通报、批复、决定、决议、命令、意见 | 上级 → 下级 |
| 平行文 | 函 | 平级之间 |
| 公布性 | 公报、公告、通告 | 面向社会 |
| 会议性 | 纪要 | 会议记录 |

---

## 一、通知

**定义**：适用于发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文。

**结构框架**：
```
发文机关标志（红头）
发文字号
────────────（红色分隔线）────────────
关于 XXXX 的通知            ← 标题（二号小标宋体）
主送机关：                  ← 顶格
  一、背景和依据            ← 为什么
  二、具体内容              ← 做什么
  三、工作要求              ← 怎么做
发文机关署名
成文日期（阿拉伯数字）
```

**常用句式**：
- 根据……精神/要求/部署，现将有关事项通知如下：
- 为……，特作如下通知：
- 以上通知，请遵照执行。
- 特此通知。

**注意事项**：
- 转发通知不重复写"现将XXX转发给你们"
- 会议通知三个要素：时间、地点、参会人员
- 任务通知三个要素：任务、责任、时限

---

## 二、通报

**定义**：适用于表彰先进、批评错误、传达重要精神和告知重要情况。

**结构框架**：
```
关于 XXXX 的通报
主送机关：
  一、基本情况/事实经过
  二、处理决定
  三、原因分析/经验教训
  四、要求
发文机关署名 + 日期
```

**常用句式**：
- 经研究决定，对……予以通报（表扬/批评）
- 为表彰先进，树立典型，经……决定对……予以通报表扬
- 希望……引以为戒，举一反三
- 特此通报。

---

## 三、报告

**定义**：适用于向上级机关汇报工作、反映情况，回复上级机关的询问。

> **⚠ 注意：报告中不得夹带请示事项。**

**结构框架**：
```
发文机关标志
X报〔2026〕X号                签发人：XXX  ← 上行文须有签发人
────────────
关于 XXXX 的报告
主送机关：
  一、基本情况/背景
  二、主要做法/工作进展
  三、存在问题（如有）
  四、下一步打算/意见建议
发文机关署名
成文日期
```

**常用句式**：
- 现将有关情况报告如下：
- 根据 XXX 要求/批示，我们……现将情况报告如下：
- 专此报告。/特此报告。
- 以上报告，请审阅。

---

## 四、请示

**定义**：适用于向上级机关请求指示、批准。

> **⚠ 关键规则：**
> - 一文一事（一个请示只写一件事）
> - 一个主送机关（不多头主送）
> - 不得越级请示
> - 文件标题不可写为"请示报告"

**结构框架**：
```
发文机关标志
X请〔2026〕X号               签发人：XXX
────────────
关于 XXXX 的请示
主送机关：
  一、请示事由（为什么请）
  二、请示事项（请示什么）
  三、可行性说明/依据
发文机关署名
成文日期
（联系人：XXX  电话：XXX）     ← 附注
```

**常用句式**：
- 为……，拟……，现就有关事项请示如下：
- 以上请示，妥否，请批示。
- 当否，请审批。
- 妥否，请批复。

---

## 五、批复

**定义**：适用于答复下级机关请示事项。

**结构框架**：
```
关于 XXXX 的批复
主送机关（必须是请示的发文机关）：
  你局（委、办）《关于……的请示》（X请〔2026〕X号）收悉。
  经研究，现批复如下：
  一、同意/原则同意/不同意……（核心答复）
  二、相关要求……（如同意，提要求）
发文机关署名 + 日期
```

**常用句式**：
- 你局《……》（X请〔2026〕X号）收悉。经研究，现批复如下：
- 原则同意……
- 此复。/特此批复。

---

## 六、函

**定义**：适用于不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。

> **关键特征**：平级机关或不相隶属机关之间使用，语气平和、商洽性强。

**结构框架**：
```
发文机关标志
X府函〔2026〕X号
────────────
关于 XXXX 的函
主送机关：
  一、发文缘由
  二、具体事项/商洽内容
  三、请求支持/期盼
发文机关署名 + 日期
（联系人/电话）
```

**常用句式**：
- 为……，现函请贵单位……为盼。
- 现就 XXXX 事宜函告如下：
- 特此函告。/专此函达。
- 请予支持为盼。/请予函复为盼。
- 此函。

---

## 七、纪要（会议纪要）

**定义**：适用于记载会议主要情况和议定事项。

**结构框架**：
```
XXXX 专题会议纪要          ← 标题含"纪要"
XX专纪〔2026〕X号
  时间：2026年X月X日
  地点：XX会议室
  主持：XXX
  出席：XXX、XXX、XXX
  列席：XXX
  议定事项：
    一、XXXXX。
    二、XXXXX。
    三、XXXXX。
出席人员名单
印发日期
```

**常用句式**：
- 会议指出，……/会议认为，……/会议强调，……
- 会议议定，……
- 会议决定，……
- 会议要求，……/会议号召，……

---

## 八、决定

**定义**：适用于对重要事项作出决策和部署、奖惩有关单位和人员、变更或者撤销下级机关不适当的决定事项。

**结构框架**：
```
关于 XXXX 的决定
主送机关/适用范围：
  一、决策背景和依据
  二、决定的具体内容（逐条列出）
  三、执行要求
发文机关署名 + 日期
附件（如有）
```

**常用句式**：
- 经研究，作出如下决定：
- 为……，决定……
- 本决定自下发之日起施行。

---

## 九、决议

**定义**：适用于会议讨论通过的重大决策事项。

**结构框架**：
```
关于 XXXX 的决议
（2026年X月X日XXXX会议通过）
  一、会议基本情况
  二、决议事项（会议指出/认为/强调/决定/号召）
发文机关署名 + 日期
```

**常用句式**：
- XX会议于X月X日至X日在XXX举行，……
- 会议指出，……/全会认为，……
- 会议决定，……/全会强调，……
- 会议号召，……

---

## 十、命令（令）

**定义**：适用于公布行政法规和规章、宣布施行重大强制性措施、批准授予和晋升衔级、嘉奖有关单位和人员。

**结构框架**：
```
XX省人民政府令
第X号
  《XXXXX》已经XX会议通过，现予公布，自XXXX年X月X日起施行。
省长  XXX（签名章）
XXXX年X月X日
```

**常用句式**：
- 《XXXXX》已经XX通过，现予公布，自XX起施行。
- 授予XXX同志"XXX"称号。

---

## 十一、公报

**定义**：适用于公布重要决定或者重大事项。

**结构框架**：
```
XXXXX 会议公报
（XXXX年X月X日通过）
  一、会议基本情况
  二、会议主要内容
  三、会议决议/决定/号召
发文机关署名 + 日期
```

**常用句式**：
- 中国共产党XX委员会第X次全体会议于XX举行，……
- 全会听取和讨论了……
- 全会号召，全党全国各族人民……

---

## 十二、公告

**定义**：适用于向国内外宣布重要事项或者法定事项。

**使用场景**：国家级重大事项、政府级重要公告。

**结构框架**：
```
关于 XXXX 的公告
  正文（简洁扼要，一事一告）
特此公告。
发文机关署名 + 日期
```

**常用句式**：
- 经……批准/研究，现将……公告如下：
- 自 XXXX 年 X 月 X 日起……
- 特此公告。

---

## 十三、通告

**定义**：适用于在一定范围内公布应当遵守或者周知的事项。

**区别**：公告面向"国内外"（重大），通告面向"一定范围"（具体社会事务）。

**结构框架**：
```
关于 XXXX 的通告
  一、通告缘由
  二、通告事项
  三、执行要求
特此通告。
发文机关署名 + 日期
```

**常用句式**：
- 为……，根据……规定，现将有关事项通告如下：
- 凡违反本通告的，由……依法处理。
- 本通告自发布之日起施行。
- 特此通告。

---

## 十四、意见

**定义**：适用于对重要问题提出见解和处理办法。

> **注意**：意见是唯一可上行、可下行、可平行的文种。

**结构框架**：
```
关于 XXXX 的意见
主送机关：
  一、重大意义/背景
  二、指导思想/基本原则
  三、主要任务/具体措施
  四、组织领导/工作要求
发文机关署名 + 日期
```

**常用句式**：
- 为……，现提出如下意见：
- 为深入贯彻落实……，结合……实际，提出如下实施意见：
- 各级各部门要高度重视，……

---

## 十五、议案

**定义**：适用于各级人民政府按照法律程序向同级人民代表大会或者人民代表大会常务委员会提请审议事项。

**结构框架**：
```
XXXXX（政府全称）
关于提请审议《XXXXX》的议案
XXX（人大或人大常委会）：
  一、议案理由/目的
  二、议案主要内容
  三、提请审议
X长/县长/市长/总理：XXX（签名）
XXXX年X月X日
```

**常用句式**：
- 为了……，……草案已经XX同意，现提请审议。
- 特提请审议。

## 文种选型决策流程

```
你需要 ↙
  向上级要批准？                      → 请示（不能写报告）
  向上级汇报工作？                    → 报告（不能夹带请示）
  向下级布置任务？                    → 通知
  答复下级请示？                      → 批复
  与平级/不相隶属单位沟通？           → 函
  公开信息给社会？                    → 公告（重大）/ 通告（一般）
  发布决策/奖励/处分？                → 决定
  记录会议内容？                      → 纪要
  会议决策需要全体确认？              → 决议
  给人大提交议案？                    → 议案
  对重大问题提出系统方案？            → 意见
  表扬或批评？                        → 通报
  公布领导层会议结果？                → 公报
  公布法规/任免/嘉奖？                → 命令（令）
```

## 公文六大禁止混用

| ❌ 错误 | ✅ 正确 |
|---------|--------|
| 请示报告（混合使用） | 请示是请示，报告是报告，二者分离 |
| 通知通告（混用） | 通知对下级，通告对社会 |
| 公告通告（混用） | 公告面大（国内外），通告面小（一定范围） |
| 函请示（对上级用函） | 对上级用"请示"，对平级用"函" |
| 纪要决定（混用） | 纪要记录事项，决定做出决策 |
| 意见命令（混用） | 意见是建议性，命令是强制性 |

### 请示错误案例对比

**❌ 错误版：**
```
东风街道办事处关于申请增设便民早餐店的请示报告
青山区政府、财政局：……我街道打算新增设的便民早餐店……
还有两百万元资金没有着落，为此，要求区政府、财政局给予支持解决。
此事关系到社区居民的切身利益，务必批准。
```

**问题点：**
1. 标题"请示报告"混用 → 应为"请示"
2. 多主送机关 → 应单一主送
3. "打算""没有着落""要求""务必" → "决定""缺口""拟请""妥否"
4. 缺少联系人和电话

**✅ 正确版：**
```
青山区东风街道办事处关于兴建便民早餐店资金缺口的请示
青山区人民政府：
……我街道决定……拟请区政府予以支持解决。
妥否，请审核批示。
（联系人：张三，联系电话：12345678901）
```
