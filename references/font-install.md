# 字体安装指南（含 WPS 专项说明）

> 公文排版依赖四种字体：方正小标宋简体、仿宋_GB2312、楷体_GB2312、黑体

---

## 一、字体需求总览

| 字体 | 用途 | Windows | macOS | WPS |
|------|------|---------|-------|-----|
| **方正小标宋简体** | 发文机关标志、标题 | ❌ 需安装 | ❌ 需安装 | ❌ 需安装 |
| **仿宋_GB2312** | 正文、主送、落款 | ⚠️ Win10/11 可能缺 | ❌ 需安装 | ✅ WPS内置仿宋 |
| **楷体_GB2312** | 二级标题、签发人 | ⚠️ Win10/11 可能缺 | ❌ 需安装 | ✅ WPS内置楷体 |
| **黑体** | 一级标题 | ✅ 自带 | ✅ 自带 | ✅ WPS内置黑体 |

---

## 二、Windows 安装

### 字体来源
- 办公专用字库（GitHub）：https://github.com/DoveOutland/Common-Chinese-office-fonts-font-library
- 方正字库官网获取方正小标宋简体

### 安装步骤
1. 下载字体文件（.ttf 或 .ttc）
2. 右键 → "安装" 或 复制到 `C:\Windows\Fonts\`
3. 重启 Word/WPS

---

## 三、WPS 专项说明

### WPS 与 Word 的字体差异

| 差异点 | Word | WPS |
|--------|------|-----|
| 仿宋_GB2312 | 可能缺失 | WPS自带仿宋字库(非GB2312版) |
| 楷体_GB2312 | 可能缺失 | WPS自带楷体字库(非GB2312版) |
| 方正小标宋简体 | 需安装 | 需安装 |
| 字体回退策略 | Windows回退 | WPS自带回退→系统回退 |

### WPS 字体设置建议
- 如果方正小标宋未安装：标题用 WPS 内置 **宋体** 二号
- 仿宋/楷体：WPS 自带版本可能名称不同（"仿宋""楷体"而非"仿宋_GB2312""楷体_GB2312"），代码中需兼容尝试

## 四、python-docx 安全字体函数

```python
FONT_FALLBACK = {
    '方正小标宋简体': ['方正小标宋简体', '宋体', 'SimSun'],
    '仿宋_GB2312': ['仿宋_GB2312', '仿宋', 'FangSong'],
    '楷体_GB2312': ['楷体_GB2312', '楷体', 'KaiTi'],
    '黑体': ['黑体', 'SimHei'],
}

def safe_font(preferred):
    """返回第一个可用的字体名，降级到宋体"""
    for name in FONT_FALLBACK.get(preferred, [preferred]):
        return name  # 实际环境依赖系统字体列表
    return '宋体'
```

## 四、WPS 操作指引

### 打开 .docx 后的快速检查

1. **页面设置**：右键 → 页面设置 → 检查页边距（上3.7/下3.5/左2.8/右2.6）
2. **字体检查**：选中正文 → WPS 字体框中显示"仿宋"即可（WPS 内置版本兼容）
3. **行距检查**：右键 → 段落 → 行距选"固定值" → 28磅
4. **首行缩进**：选中正文 → 拖动标尺上方的倒三角 → 定位到0.74cm（约2个汉字）

### WPS 与 Word 的关键差异

| 操作 | Word 位置 | WPS 位置 |
|------|----------|---------|
| 页面设置 | 布局 → 页边距 | 页面布局 → 页边距 |
| 字体设置 | 开始 → 字体 | 开始 → 字体（WPS 用默认字库） |
| 行距设置 | 段落 → 缩进和间距 | 右键段落 → 缩进和间距 |
| 首行缩进 | 段落 → 特殊格式 | 右键段落 → 特殊格式 → 首行缩进 |
| 查看字数 | 审阅 → 字数统计 | 工具 → 字数统计 |

### WPS 字体注意事项
- WPS 打开 python-docx 生成的文件时，如果字体缺失会弹出"字体替换"提示，直接确认即可
- WPS 2023+ 版本已内置仿宋/楷体字库，打开后显示正确
- 唯一需要手动安装的是**方正小标宋简体**（标题专用）

## 五、macOS / Linux

### macOS
1. 下载 .ttf 文件
2. 双击 → "安装字体"
3. 或放入 `~/Library/Fonts/`

### Linux
```bash
mkdir -p ~/.fonts
cp *.ttf ~/.fonts/
fc-cache -fv
```

> **注意**：python-docx 生成的文件在缺字体时仍能保存。在缺少小标宋的系统上，标题将显示为替代字体（Word 自动回退为宋体）。
