# 公文写作技巧指南

> 整合自 KaguraNanaga/official-document-writing-skill 项目的写作技巧

## 一、公文语言四大原则（详解）

### 1. 准确（Accuracy）

公文语言的第一要求。用词准确、造句准确、表意准确。

#### 常见用词修正

| 错误用词 | 问题 | 正确用法 |
|---------|------|---------|
| 截止2014年10月30日 | "截止"后不能直接跟时间 | 截至2014年10月30日 |
| 上世纪八十年代以来 | "世纪""年代"用阿拉伯数字 | 20世纪80年代以来 |
| 二〇〇六年 | 公文要求阿拉伯数字 | 2006年 |
| 老百姓 | 口语化 | 市民、群众、居民 |
| 一把手 | 口语化 | 主要负责人、主管领导 |
| 打算 | 口语化 | 决定、拟定、计划 |
| 没有着落 | 口语化 | 缺口、存在困难 |
| 要求（对上级） | 语气强硬 | 拟请、恳请、建议 |

#### 句子成分完整

❌ "通过学习，使全体干部提高了认识。"（缺少主语）
✅ "通过学习，全体干部提高了认识。"

### 2. 平实（Simplicity）

朴实无华、语意实在，不堆砌辞藻，不溢美不虚饰。

❌ "在市委、市政府的英明领导下，全区上下万众一心、众志成城，以雷霆万钧之势……取得了举世瞩目的辉煌成就。"
✅ "在市委、市政府的正确领导下，全区上下团结协作，圆满完成了年度目标任务。"

**要求：** 少用形容词/副词，多用名/动词，用数据说话。

### 3. 简洁（Conciseness）

开门见山、言之有物，尽可能使用短句。

❌ "为了使本次会议精神得到全面贯彻落实，切实推动各项工作有效开展，经研究决定，特制定本实施方案。"
✅ "为贯彻本次会议精神，推动工作落实，特制定本方案。"

**方法：** 开门见山、删繁就简、使用短句、词语精准。

### 4. 庄重（Formality）

郑重、严肃，语气坚定、格调凝重，使用规范的书面语言。

❌ "这事儿得好好琢磨琢磨，不能拍脑袋决策。"
✅ "此事需认真研究，慎重决策。"

**稳妥词语：**
- "应予肯定"不用"就是好"
- "原则同意"不用"完全同意"（需补充完善时）
- "拟同意"不用"同意"（未经最终决定时）

## 二、公文专用语分类速查

| 类别 | 常用词语 |
|------|---------|
| **开头** | 根据、按照、遵照、为、为了、关于、鉴于、兹、欣闻 |
| **承启** | 现将、特作如下、特提出以下、综上所述 |
| **结尾** | 特此通知、妥否请批示、当否请批复、以上报告请审阅、此复 |
| **经办** | 经、业经、已将、试行、暂行、办理、施行 |
| **期请** | 恳请、拟请、敬请、盼予、希予、望予、务希 |
| **判断** | 系、确系、显系、应、本应、理当 |
| **谦敬** | 承蒙、蒙、不胜、鼎力支持、大力协助 |
| **时态** | 兹、现已、业已、届时、值此、如期、按期 |

## 三、标题拟定技巧

### "六查法"

| 检查项 | 要求 | ❌ 错误 | ✅ 正确 |
|--------|------|--------|--------|
| 准确恰当 | 题文相符，宽窄适度 | 标题"加强干部队伍建设"，内容只写培训 | 标题改为"加强干部培训工作" |
| 明确集中 | 单一主题，不杂乱 | 标题写三个主题 | 分开或提炼统一主题 |
| 照应总题 | 小标题与大标题呼应 | 总题优化营商，小标题写党建 | 都围绕营商主题 |
| 合乎逻辑 | 领属/并列关系正确 | 领导+保障+业务（不在同一层次） | 组织领导+投入保障+队伍建设 |
| 艺术性 | 生动有新意 | 平淡无趣 | 运用对仗、排比、形象化语句 |
| 匀称和谐 | 句式字数整齐 | 长短不一 | 统一为四字或六字短语 |

### "三个注重"

1. **注重积累** — 从报刊/文件/讲话中收集好标题，建立素材库
2. **注重模仿** — 借鉴"动作+主题+效果"结构："深化XX改革，提升XX效能"
3. **注重实践** — 先拟定标题再写内容，边写边改，写完再打磨

## 四、经验提炼四步法

### 第一步：罗列工作、整理分类
列出所有工作，按业务领域/工作性质/成效/时间分类。

### 第二步：归纳亮点、提炼主题
从分类中找创新性、有影响力、有成效的工作，定核心主题。

**提炼标准：** 创新性、示范性、实效性、典型性

### 第三步：划分层次、打磨标题
根据主题划分3-5个逻辑层次，为每层拟定标题。

**常见结构：**
```
一、坚持问题导向，找准改革突破口     （为什么改）
二、坚持系统思维，统筹推进改革       （怎么改）
三、坚持科技赋能，提升智慧化水平     （用什么手段）
四、坚持服务为本，提升群众满意度     （达到什么效果）
```

### 第四步：严谨行文、反复修改
- 文字精练：删可有可无的词语
- 标题盖内容：不帽子大内容小
- 逻辑清楚：各层不交叉不重复（MECE原则）

## 五、各文种写作套路速记

| 文种 | 开头 | 主体 | 结尾 |
|------|------|------|------|
| **通知** | 依据+目的 | 事项+要求 | 特此通知 |
| **请示** | 缘由（政策+实际） | 请示事项（具体明确） | 妥否，请批示 |
| **报告** | 依据+过渡句 | 做法+成效+问题 | 今后打算/特此报告 |
| **总结** | 背景+成绩概述 | 具体做法/经验 | 问题+打算 |
| **函** | 缘由/来函收悉 | 事项/答复 | 此函/特此函复 |
| **纪要** | 会议基本信息 | 讨论+议定事项 | 出席名单 |
| **批复** | 来文收悉 | 答复内容+要求 | 此复 |

## 六、写作进阶建议

### 提升公文底蕴
1. 学习业务知识 — 熟悉本领域政策法规和术语
2. 积累素材库 — 建立政策文件库+典型事例库+数据资料库+精彩语句库
3. 研读优秀范文 — 学习立意、框架、语言

### 培养文字敏感
1. **朗读法** — 写完后大声朗读，发现不通顺处
2. **比较法** — 同一内容尝试多种表达，选最佳
3. **换位思考** — 站在读者角度审视是否清晰易懂

### 完成后的自我审查
- [ ] 内容：紧扣主题、观点正确、材料典型、数据准确
- [ ] 结构：层次清晰、逻辑严密、详略得当、前后连贯
- [ ] 语言：准确规范、简洁明了、平实庄重、无错词病句
- [ ] 格式：文种正确、要素齐全、字体规范、排版美观

> **金句：** "文经我手无差错，事经我办请放心。"
