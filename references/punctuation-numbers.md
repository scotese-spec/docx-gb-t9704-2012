# 标点符号与数字用法规范

> 依据：GB/T 15834《标点符号用法》、GB/T 15835《出版物上数字用法》

---

## 一、标点符号规范（GB/T 15834）

### 1.1 核心原则

**公文正文统一使用全角中文标点，禁止混入英文（半角）标点。**

### 1.2 常见标点对照表

| 符号 | 中文全角 | 英文半角（禁用） | 说明 |
|------|---------|----------------|------|
| 逗号 | `，` | `,` | |
| 句号 | `。` | `.` | |
| 冒号 | `：` | `:` | |
| 分号 | `；` | `;` | |
| 问号 | `？` | `?` | |
| 叹号 | `！` | `!` | |
| 双引号 | `""` | `""` 或 `"` | 中文引号前后不同 |
| 单引号 | `''` | `''` 或 `'` | |
| 括号 | `（）` | `()` | 中文括号占两字符宽 |
| 顿号 | `、` | — | 中文特有 |
| 书名号 | `《》` | — | 中文特有 |
| 破折号 | `——` (两字线) | `--` `—` | |
| 省略号 | `……` (两字符) | `...` `…` | |
| 连接号 | `—` (一字线) | `-` `–` | 用于页码/数值范围 |
| 间隔号 | `·` | `.` | 如"约翰·史密斯" |

### 1.3 快速修复英文标点

```python
import re

def fix_punctuation_to_chinese(text):
    """将英文标点替换为中文全角标点"""
    mapping = {
        ',': '，', '.': '。', ':': '：', ';': '；',
        '?': '？', '!': '！', '(': '（', ')': '）',
        '<': '《', '>': '》', '[': '〔', ']': '〕',
    }
    # 注意：引号处理需要上下文判断，此处做简单替换
    for en, cn in mapping.items():
        text = text.replace(en, cn)
    # 处理省略号
    text = text.replace('...', '……').replace('…', '……')
    # 处理破折号
    text = re.sub(r'--+', '——', text)
    return text

# python-docx 全文修复
def fix_docx_punctuation(doc):
    from docx import Document
    for p in doc.paragraphs:
        for r in p.runs:
            r.text = fix_punctuation_to_chinese(r.text)
    return doc
```

### 1.4 标点排版规则

| 规则 | 说明 |
|------|------|
| 句号| 段末用句号，不用逗号代替 |
| 顿号| 并列词/词组用顿号，两词之间不加顿号，"和"前不加顿号 |
| 分号| 分句间用分号，最后一项用句号 |
| 冒号| 提示下文、引出内容用冒号，不在无提示处乱用 |
| 连接号| 一字线" — "用字号/日期范围（1—3月），短横"-"用于复合名词 |
| 破折号| 两字线"——"用于解释说明 |
| 省略号| 两字符"……"，不用多于或少于 |
| 间隔号| "·" — 音译名分隔、书名篇名分隔 |
| 引号嵌套| 双引号在外，单引号在内：`"他说'是的'"` |
| 书名号嵌套| 双书名号在外，单在内：`《XXX〈XXX〉XXX》` |
| 引导词后标点| "指出""强调""要求"后用"："（全角冒号） |

### 1.5 公文特有标点

| 用途 | 标点 | 示例 |
|------|------|------|
| 发文字号年份 | 六角括号 `〔〕` | `国发〔2026〕1号` |
| 引用的文件名称 | `《》` | `根据《党政机关公文处理工作条例》` |
| 附件名称后 | **不加标点** | 附件：1. XXXXXXX |
| 主送机关末尾 | 全角冒号 `：` | `省政府：` |

## 二、数字用法规范（GB/T 15835）

### 2.1 数字类型

| 类型 | 阿拉伯数字 | 汉字数字 |
|------|----------|---------|
| 公历日期时间 | ✅ 2026年5月15日 | ❌ 二〇二六年五月十五日 |
| 发文字号 | ✅ 〔2026〕1号 | ❌ |
| 统计数据 | ✅ 增长12.5% | ❌ |
| 法律条文 | ✅ 第3条第2款 | ✅ 第三条第二款 |
| 已数词定型 | — | ✅ 星期五、"十三五"规划 |
| 约数/估算 | — | ✅ 数十人/三五天 |
| 党政会议 | — | ✅ 党的二十大/二十届三中全会 |
| 军队序列 | — | ✅ 第三十八集团军 |
| 历史朝代 | — | ✅ 清康熙年间 |
| 整数（零头） | ✅ 2000亿元 | ✅ 两千亿元 |

### 2.2 日期格式

```
✅ 正确写法：
  2026年5月15日
  2026年5月
  XX会议（2026年5月15日）

❌ 错误写法：
  二〇二六年五月十五日（公文成文日期不用大写）
  2026.5.15（不用缩写）
  26年5月15日（年份不缩略）
  2026年05月15日（月日不编虚位）
```

### 2.3 金额格式

```
✅ 正确：
  1200万元
  3.5亿元
  2000美元

❌ 错误：
  12000000元（大数额应换算为万/亿）
  一千二百万元（统计数据不用大写）
```

### 2.4 比例和百分比

```
✅ 正确：
  完成率85%
  同比增长12.5%
  占比1/3（三分之一，不用阿拉伯数字也可）

❌ 错误：
  完成率百分之八十五（统计数据不用大写比例）
```

### 2.5 发文字号

```
✅ 正确格式：
  国发〔2026〕1号
  中办发〔2026〕5号
  X府发〔2026〕10号

关键规则：
  - 年份用六角括号 〔〕 不用 []、()、【】
  - 发文顺序号不编虚位：1号 不是 01号
  - 顺序号不加"第"字：1号 不是 第1号
```

### 2.6 度量衡

公文中计量单位用法应当符合 GB 3100、GB 3101、GB 3102：

```
长度：米(m)、千米/km、厘米/cm、毫米/mm
质量：千克/kg、克/g、吨/t
面积：平方米/m²、公顷/hm²、平方公里/km²
容积：升/L (l)、毫升/mL (ml)
功率：千瓦/kW
```

## 三、公文中标点数字快速检查清单

- [ ] 全文无英文半角逗号 `.` 应替换为 `，`
- [ ] 全文无英文半角句号 `.` 应替换为 `。`
- [ ] 全文无半角括号 `()` 应替换为 `（）`
- [ ] 全文无英文引号 `""` 应替换为 `""`
- [ ] 发文字号年份用六角括号 `〔〕`
- [ ] 成文日期用阿拉伯数字（2026年5月15日）
- [ ] 成文日期月日不编虚位（5月不是05月）
- [ ] 页编号用半角宋体阿拉伯数字
- [ ] 一至十（小于11）的整数用汉字（一项工作、三个方面）
- [ ] 大于10的数字用阿拉伯数字（12个部门、35人）
- [ ] 专用名词/术语中的数字保留原型（"十三五""三严三实"）
- [ ] 附件名称后不加标点符号
- [ ] 引号嵌套正确（双在外、单在内）
