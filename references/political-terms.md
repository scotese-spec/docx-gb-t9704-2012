# 党政机关公文规范词汇速查

> **重要说明**
> - 本文所列规范词汇为党政机关公文中常用的规范表述
> - **所有术语以中共中央、国务院最新文件表述为准**
> - 本文仅为参考，用户起草公文时应核对最新政策文件
> - 本文件不包含偏离中央精神的非规范表述

---

## 一、指导思想类表述

### 总表述
- 以习近平新时代中国特色社会主义思想为指导
- 全面贯彻党的二十大精神（按实际届次更新）
- 深入学习贯彻习近平总书记系列重要讲话精神
- 深入贯彻落实习近平总书记关于XXXX的重要论述

### 发展理念
- 坚持新发展理念 / 立足新发展阶段、贯彻新发展理念、构建新发展格局
- 推动高质量发展 / 实现高质量发展
- 以人民为中心的发展思想
- 统筹发展和安全

## 二、政治站位类表述

### 通用
- 提高政治站位 / 增强政治意识
- 深刻领悟"两个确立"的决定性意义 / 增强"四个意识" / 坚定"四个自信" / 做到"两个维护"
- 在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致
- 确保党中央决策部署不折不扣落到实处

### 责任担当
- 坚持人民至上、生命至上
- 以时时放心不下的责任感抓好XXXX
- 守土有责、守土负责、守土尽责

## 三、工作落实类表述

### 组织领导
- 党政同责、一岗双责、齐抓共管、失职追责
- 主要负责同志亲自部署、靠前指挥，分管负责同志深入一线、现场督导
- 层层压实责任 / 将XXXX纳入目标考核

### 督查落实
- 建立工作台账，实行销号管理
- 定期调度通报 / 对工作不力的严肃追责问责
- 以钉钉子精神推进各项工作落实

### 问题整改
- 立行立改、即知即改
- 举一反三、标本兼治
- 建立长效机制

## 四、作风建设类表述

### 通用
- 力戒形式主义、官僚主义
- 坚持实事求是
- 深入基层、深入一线、深入群众
- 急群众之所急、想群众之所想
- 以实实在在的工作成效取信于民

### 调研
- 坚持问题导向 / 大兴调查研究之风
- 采取"四不两直"方式（不发通知、不打招呼、不听汇报、不用陪同接待，直奔基层、直插现场）

## 五、会议类常用表述

### 会议动词（按强度递增）
- 指出 → 强调 → 要求 → 部署
- 认为 → 决定 → 号召

### 使用规范
| 场景 | 规范用语 |
|------|---------|
| 习近平总书记讲话 | **指出、强调** |
| 会议讨论 | **认为** |
| 会议决策 | **决定、议定** |
| 会议号召 | **号召** |

> ⚠ "指出/强调/要求"有强度层级，不可混淆。只有总书记/最高领导层可用"强调""要求"。

## 六、领域专用表述

### 安全生产
- 安全生产重于泰山
- 管行业必须管安全、管业务必须管安全、管生产经营必须管安全
- 隐患排查整治 / 双重预防机制
- 坚决遏制重特大事故发生

### 改革
- 深化"放管服"改革 / 优化营商环境
- 证照分离 / 一窗受理、一网通办
- 打通服务群众"最后一公里"

### 生态环保
- 绿水青山就是金山银山
- 人与自然和谐共生
- 坚决打好污染防治攻坚战

### 乡村振兴
- 产业兴旺、生态宜居、乡风文明、治理有效、生活富裕
- 巩固拓展脱贫攻坚成果同乡村振兴有效衔接

### 党建
- 全面从严治党永远在路上
- 一体推进不敢腐、不能腐、不想腐
- 打造忠诚干净担当的高素质干部队伍

## 七、常用修饰语规范

| ❌ 禁用或慎用 | ✅ 规范用语 | 说明 |
|-------------|----------|------|
| 狠抓 | 强化、加强、加大力度 | "抓"口语化 |
| 一把手 | 主要负责同志 | 党内规范称谓 |
| 全体同志/全体干部 | 全体党员干部 | 党外慎用 |
| 必须（对上级） | 请、恳请 | 上行文语气 |
| 讲话/发言/说了（指领导） | 指出、强调、要求 | 层级分明 |

## 八、引用文件规范

### 常见规范引用格式

```
根据《党政机关公文处理工作条例》（中办发〔2012〕14号）的有关规定
依据《中华人民共和国安全生产法》（2021年修订版）
按照《国务院关于XXXX的决定》（国发〔202X〕X号）要求
根据中共XX省委办公厅、XX省人民政府办公厅《关于XXXX的通知》（X办发〔202X〕X号）
```

### 注意事项
- 引用文件时标注发文字号（中办发〔2012〕14号）
- 年份用六角括号〔〕，不用[]()
- 机构全称在前，文件标题在后，发文字号在最后

## 十、真实公文提取的规范句式

> 以下句式提取自 www.gov.cn 国务院文件（2026年5月）。
> 示例：国办发〔2026〕14号（通知）、国函〔2026〕38号（批复）、国令第836号（命令）

### 通知印发句式
```
《XXXX》已经党中央、国务院同意，现印发给你们，请认真贯彻执行。
```

### 批复开头句式
```
你们关于XXXX的请示收悉。现批复如下：
一、同意自即日起……
二、有关部门要根据上述调整，及时对本部门规章和规范性文件作相应调整，
   统筹发展和安全，建立相适应的管理制度。
三、国务院将根据实施情况，适时对本批复内容进行调整。
```

### 法规公布句式
```
《XXXX》已经2026年X月X日国务院第XX次常务会议修订通过，
现予公布，自2026年X月X日起施行。
```

### 总体要求段落模板
```
2026年是"十五五"开局之年。XXXX工作的总体要求是：在以习近平同志为
核心的党中央坚强领导下，坚持以习近平新时代中国特色社会主义思想为指导，
全面贯彻落实党的二十大和二十届历次全会精神，聚焦XXXX，统筹XXXX，
加强XXXX，为以中国式现代化全面推进强国建设、民族复兴伟业提供有力保障。
```

### 其他高频句式

| 句式 | 用途 |
|------|------|
| 经……同意，现印发给你们，请认真贯彻执行 | 通知印发 |
| 已经……通过，现予公布，自……起施行 | 法规公布 |
| 你们关于……的请示收悉。现批复如下： | 批复开头 |
| 坚持突出重点、急用先行、统筹兼顾 | 工作原则 |
| 加强组织领导、完善工作机制、压紧压实责任 | 责任部署 |
| 适时对……进行调整 | 政策留弹性 |
| 高质效完成各项任务 | 任务要求 |
| （此件公开发布） | 公开发布标识 |

## 十一、时效性提醒

| 需要关注的变化 | 说明 |
|--------------|------|
| "党的二十大" vs "二十大"（正式名称是"中国共产党第二十次全国代表大会"） | 公文首次用全称，后可用简称 |
| 领导职务称谓 | 以最新任免为准 |
| 重要提法 | 以中央全会、两会最新表述为准 |
| 法律法规名称 | 含"试行""暂行"的文件须标注完整 |
