# 公文用语规范

> 依据：中办发〔2012〕14号、GB/T 9704-2012

---

## 一、公文语言四原则

### 1. 准确（Accuracy）
- 概念明确，用词精准，避免歧义
- 数据精确，引用有据
- 判断恰当，推理严密
- 忌：大概、也许、差不多、好像、可能、似乎

### 2. 平实（Simplicity）
- 语言朴实，不用渲染和夸张
- 实事求是，一是一、二是二
- 忌："辉煌成就""伟大胜利""前所未有""极大鼓舞""非常正确"

### 3. 简洁（Conciseness）
- 字斟句酌，言简意赅
- 删去可有可无的字词
- 忌：长句嵌套、重复啰嗦、"的"字泛滥

| 啰嗦 | 简洁 |
|------|------|
| 进行认真的研究讨论 | 研究 |
| 在……基础上，经过……采取…… | 为…… |
| 召开了座谈会并进行了讨论 | 召开座谈会 |
| 开展了对……的检查工作 | 检查了…… |
| 予以坚决的打�� | 打击 |

### 4. 庄重（Formality）
- 使用规范公文用语
- 不用口语、俚语、网络用语
- 不用情绪化语言

| 口语/俚语 | 公文用语 |
|----------|---------|
| 搞定、摆平 | 完成、解决 |
| 讲话、发言、说了 | 指出、强调、要求 |
| 好多、很多 | 大量、众多 |
| 马上、快点 | 立即、尽快 |
| 好好干、加油干 | 认真抓好落实、扎实推进 |

## 二、常用公文句式（按用途分类）

### 2.1 开头句式（引言）

| 用途 | 句式 |
|------|------|
| 依据上级精神 | 根据……精神/部署/要求 |
| 依据文件 | 根据《……》，结合……实际 |
| 依据会议 | XX会议决定/指出 |
| 为达到目的 | 为……/为了……/为进一步…… |
| 经研究决定 | 经……研究，决定…… |
| 承接上级批示 | 根据 XXX 同志批示精神 |
| 回应下级请示 | 你局（委）《……》收悉 |

### 2.2 过渡句式

| 用途 | 句式 |
|------|------|
| 通知类过渡 | 现将有关事项通知如下： |
| 意见类过渡 | 现提出如下意见：/现提出如下实施意见： |
| 报告类过渡 | 现将有关情况报告如下： |
| 请示类过渡 | 现就有关事项请示如下： |
| 批复类过渡 | 经研究，现批复如下： |
| 决定类过渡 | 经研究，作出如下决定： |
| 通报类过渡 | 现将有关情况通报如下： |
| 公告/通告类 | 现将……公告（通告）如下： |
| 会议纪要 | 会议议定了以下事项： |

### 2.3 要求句式

| 用途 | 句式 |
|------|------|
| 强调重要性 | 要切实加强……/要高度重视…… |
| 布置任务 | 各有关部门要……/各级……务必…… |
| 明确责任 | 由……牵头/负责/承担…… |
| 时间要求 | 于 X 月 X 日前完成/报送 |
| 请示批复 | 请于 X 月 X 日前报我部备案 |
| 一般执行 | 请遵照执行/请认真贯彻执行 |
| 参考执行 | 请结合实际参照执行 |

### 2.4 结束句式

| 文种 | 结束语 |
|------|--------|
| **请示** | 妥否，请批示。/当否，请审批。/以上请示，请批复。 |
| **报告** | 特此报告。/专此报告。/以上报告，请审阅。 |
| **批复** | 此复。/特此批复。 |
| **函** | 此函。/特此函告。/请予函复。/请予支持为盼。 |
| **通知** | 特此通知。/以上通知，请遵照执行。 |
| **通报** | 特此通报。 |
| **公告/通告** | 特此公告。/特此通告。 |
| **意见** | 以上意见，请结合实际贯彻执行。 |
| **决定** | 本决定自下发之日起施行。 |
| **决议** | 会议号召，…… |
| **议案** | 现提请审议。/特提请审议。 |

### 2.5 表态句式

| 态度 | 句式 |
|------|------|
| 完全同意 | 同意。/原则同意。/经研究，同意…… |
| 部分同意 | 原则同意……，同时要求…… |
| 不同意 | 暂不同意，请……后再报。/不予批准。 |
| 知晓 | 收悉。/知悉。/阅悉。 |
| 认可 | 充分肯定。/给予肯定。 |
| 指出问题 | 存在……问题/不足，须引起高度重视。 |

### 2.6 常用连接词

| 关系 | 词语 |
|------|------|
| 并列 | 和、与、及、以及、同时 |
| 递进 | 进一步、特别是、尤其是、在此基础上 |
| 因果 | 因此、鉴于此、基于此 |
| 转折 | 但是、然而、不过 |
| 目的 | 为了、为、旨在 |
| 手段 | 通过、以、采取 |

## 三、常用词组与避讳

### 3.1 高频规范词组

| 类别 | 词组 |
|------|------|
| 组织领导 | 加强领导、健全机制、落实责任、层层压实 |
| 工作推进 | 扎实推进、有序开展、稳步推进、持续深化 |
| 落实执行 | 狠抓落实、贯彻落实、逐项落实、落地见效 |
| 监督检查 | 加强督查、跟踪问效、考核问责、定期通报 |
| 总结评估 | 总结经验、查找不足、评估成效、分析原因 |
| 政策用语 | 顶层设计、制度建设、长效机制、标本兼治 |
| 改革类 | 深化改革、攻坚克难、重点突破、先行先试 |

### 3.2 应避讳和慎用的词语

| ❌ 禁用词 | ✅ 替代词 |
|----------|---------|
| 狠抓（过于空洞） | 认真落实/扎实推进 |
| 强力推进（口语化） | 大力推进/积极推进 |
| 全体同志/全体干部 | 全体党员干部（党外慎用） |
| 一把手（俚语） | 主要负责同志 |
| 一把手负总责 | 主要负责同志为第一责任人 |
| 严打、重拳出击 | 依法严厉惩处 |
| 必须（过于强硬） | 要（下行文可用）、请（上行文/平行文） |

### 3.3 公文称谓规范

| 对象 | 称谓 |
|------|------|
| 上级机关 | 贵部、贵厅、贵局（公函）/ 你部、你厅、你局（下行） |
| 个人 | 同志（党内通用） |
| 单位 | XX 局（委、办、部、厅）+ 规范简称（第一次出现用全称） |
| 文件引用 | 《……》（书名号），后用发文字号 |
| 自称（上行文） | 我局/我部/我厅/我委 |
| 自称（下行文） | 部（厅、局）里、"本部"等 |

## 四、公文写作流程

```
第一步：明确文种       ← 确定用请示/报告/通知/函…
第二步：列出提纲       ← 写什么？分几部分？
第三步：拟定标题       ← "关于+事由+文种"
第四步：起草正文       ← 依据→事项→要求
第五步：规范用语       ← 对照本文件四原则检查
第六步：检查标点数字   ← 全角标点、阿拉伯日期
第七步：质量终审       ← 对照质量检查清单
```

### 标题写作六查法

| 检查项 | 正确 | 错误 |
|--------|------|------|
| 要素齐全 | 关于+事由+文种 | 缺少"关于"或文种 |
| 介词单一 | 关于……的通知 | 对于……关于……的通知 |
| 中心词搭配 | 关于加强……工作的通知 | 关于加强……的管理（缺少中心词） |
| 不用标点 | 直接书写 | 加书名号《》、引号"" |
| 事由明确 | 关于开展安全生产检查的通知 | 关于工作的通知 |
| 长短适度 | 20-40字为宜 | 超过50字须分行 |

## 五、公文中常见标点用法

| 符号 | 用法 |
|------|------|
| ，（逗号） | 句内停顿 |
| 。（句号） | 句末 |
| 、（顿号） | 并列词/词组间 |
| ； （分号） | 复句内并列分句间 |
| ：（冒号） | 提示下文 |
| ""（双引号） | 引用/强调 |
| ''（单引号） | 双引号内再引 |
| 《》（双书名号） | 文件名/法规名 |
| <>（单书名号） | 《》内再用 |
| （）（圆括号） | 补充说明/注释 |
| ——（破折号） | 解释说明 |
| …（省略号） | 省略 |
| —（一字线） | 页码/连接 |

## 六、语气等级（上行/下行/平行文）

| 文种方向 | 语气 | 注意 |
|---------|------|------|
| **上行文**（请示/报告） | 尊敬、谦恭 | 用"请""报""呈"等，不定多用"必须" |
| **下行文**（通知/决定/批复） | 肯定、明确 | 可用"要""必须""务必"，但不傲慢 |
| **平行文**（函） | 平等、商询 | 用"请""酌""盼"等，语气和缓 |
