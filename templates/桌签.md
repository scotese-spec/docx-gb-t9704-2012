# 桌签模板

## 适用场景
适用于会议室内标识参会人员座位的姓名桌签。非正式公文文种，属会议辅助用品，用于主席台、圆形会议桌等场合。

## 结构框架
```
[桌签正面]
┌──────────────────────────┐
│                          │
│       [姓名]             │
│                          │
└──────────────────────────┘

[桌签反面]（双面打印时）
┌──────────────────────────┐
│                          │
│       [姓名]             │
│                          │
└──────────────────────────┘
```

## 常用格式规格
- 标准尺寸：195mm × 65mm 或 210mm × 75mm
- 字体：方正小标宋简体或楷体，字号初号或小初
- 单位名称较小字号置于姓名下方（可选）
- 红色（党委会议）或黑色（行政会议）

## 常用排版要点
- 姓名居中，一般两个字时空一格（如：「张 三」）
- 三个字及以上的姓名连续排列（如：「欧阳修远」）
- 有职务时可标注职务，字号小于姓名
- 参加人员较多时按姓氏笔画或职务排序

## 注意事项
- 桌签颜色应与会议性质匹配：党内会议用红色，行政会议用黑色。
- 双面打印确保正反两面内容一致，便于多角度观看。
- 姓名核对无误后方可打印，遇多音字应提前确认读音。
- 临时增加人员可用手写方式补充，字形应工整。
