# 公告模板

## 适用场景
适用于向国内外宣布重要事项或法定事项。发文机关级别较高，事项具有重大性、权威性特征。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号（可选）]

[主体]
[标题] [发文机关]公告
（或：关于[事由]的公告）
[正文]：
　　[开头段：说明公告的目的和依据]
　　[事项段：具体公告内容]
　　[结尾：通常以"特此公告"或"现予公告"结尾]

[版记]
────────────────────────────
[发文机关（印章）]
[成文日期]
────────────────────────────
[印发机关]                        [印发日期]
```

## 常用句式
- 「根据《×××法》第×条规定，现将×××事项公告如下。」
- 「经×××批准，自××××年×月×日起，对×××进行调整如下。」
- 「现将[选举/任命/通过]的×××名单予以公告。」
- 「特此公告。」「现予公告。」
- 「以上事项，自公告发布之日起×日内，如有异议，请向×××提出。」

## 注意事项
- 公告一般通过媒体公开发布，不标注主送机关。
- 公告事项必须具有重大性，不得将一般性通知以公告形式发布。
- 公告语言应庄重、严谨，数据精准，避免模糊表述。
