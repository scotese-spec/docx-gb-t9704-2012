# 议案模板

## 适用场景
适用于各级人民政府按照法律程序向同级人民代表大会或人民代表大会常务委员会提请审议事项。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号]

[主体]
[标题] 关于提请审议[事由]的议案
[主送机关]：[同级人民代表大会或其常务委员会]
　　[案由段：说明提请审议事项的背景、目的和法律依据]
　　[案据段：阐述提请审议的理由和必要性]
　　[方案段：详细列出提请审议的具体内容]
　　[结尾：请予审议]

[签署]
[发文机关职务署名]
[成文日期]

[版记]
────────────────────────────
[印发机关]                        [印发日期]
```

## 常用句式
- 「根据《中华人民共和国×××法》第×条规定，现提请审议《×××（草案）》。」
- 「为了[目的]，经[会议/程序]研究，拟对×××进行调整/修改，请予审议。」
- 「为做好×××工作，建议[具体建议内容]。」
- 「以上议案，请予审议。」
- 「提请任命/免去×××同志[职务]，请审议决定。」

## 注意事项
- 议案的发文机关只能是本级人民政府，主送机关只能是同级人民代表大会或其常务委员会。
- 议案须由行政首长签署，并加盖政府公章。
- 议案正文应说明法律依据，附上相关说明材料和法律文本草案。
