# 通知模板

## 适用场景
适用于发布、传达要求下级机关执行和有关单位周知或执行的事项，批转、转发公文，任免人员。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号]                                    [签发人（可选）]

[主体]
[标题] 关于[事由]的通知
[主送机关]:
　　[引言段：背景、目的、依据]
　　现将有关事项通知如下：
　　一、[事项一：目标/要求/安排]
　　二、[事项二：具体措施/步骤]
　　三、[事项三：责任分工/时限]
　　[结尾段：执行要求或补充说明]
　　（此页无正文）

[版记]
────────────────────────────
[发文机关]
[成文日期]
（[联系方式/附件说明]）
────────────────────────────
[抄送机关：×××，×××]
[印发机关]                        [印发日期]
```

## 常用句式
- 「根据《×××》第×条规定，现将×××有关事项通知如下。」
- 「为深入贯彻落实×××精神，进一步做好×××工作，现就有关事项通知如下。」
- 「请各单位高度重视，结合实际认真贯彻执行，并于[日期]前将落实情况报送[受理机关]。」
- 「本通知自印发之日起施行。」
- 「以上通知，请遵照执行。」

## 注意事项
- 通知应一事一文，事项具体明确，便于下级执行。
- 执行要求应有明确的时间节点和责任主体。
- 若涉及多个部门，应明确牵头单位与配合单位。
