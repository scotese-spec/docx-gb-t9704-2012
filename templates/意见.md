# 意见模板

## 适用场景
适用于对重要问题提出见解和处理办法。行文方向灵活，可作为上行文、下行文或平行文使用。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号]

[主体]
[标题] 关于[事由]的意见
[主送机关]:
　　[开头段：说明提出意见的背景、目的和依据]
　　[主体段：分条阐述具体意见和建议]
　　一、[意见一：提高思想认识/明确目标要求]
　　二、[意见二：主要任务/工作措施]
　　三、[意见三：保障机制/组织实施]
　　[结尾段：提出执行要求和期望]

[版记]
────────────────────────────
[发文机关（印章）]
[成文日期]
────────────────────────────
[抄送机关：×××，×××]
[印发机关]                        [印发日期]
```

## 常用句式
- 「为[目的]，根据[依据]，现就×××提出以下意见。」
- 「一、充分认识×××的重要意义。……」
- 「各地区各部门要结合实际，研究制定具体落实措施。」
- 「以上意见，请结合实际认真贯彻落实。」（下行时用）
- 「以上意见如无不妥，建议批转各地区各部门执行。」（上行时用）

## 注意事项
- 作为上行文的意见，应按请示性公文程序和要求办理。
- 作为下行文的意见，文中对贯彻执行有明确要求的，下级机关应遵照执行。
- 意见的写作应观点鲜明、措施可行、便于操作。
