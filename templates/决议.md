# 决议模板

## 适用场景
适用于会议讨论通过的重大决策事项。须经法定会议审议并表决通过后方可发布，具有权威性和约束力。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号]

[主体]
[标题] 关于[事由]的决议
（[××××年×月×日×××会议通过]）
[正文段一：阐述决议的背景和意义]
[正文段二：分条列述会议通过的内容]
　一、[通过事项一]
　二、[通过事项二]
　三、[通过事项三]
[正文段三：发出号召或提出要求]

[版记]
────────────────────────────
[发文机关]
[成文日期]
────────────────────────────
[抄送机关：×××，×××]
[印发机关]                        [印发日期]
```

## 常用句式
- 「[会议名称]于[时间]在[地点]召开，会议听取并审议了×××，通过了如下决议。」
- 「会议认为，×××具有重要意义/取得了显著成绩。」
- 「会议决定/会议批准了×××，要求各级各部门认真贯彻执行。」
- 「大会号召，全体[对象]紧密团结起来，为[目标]而共同奋斗。」
- 「此决议自通过之日起生效。」

## 注意事项
- 决议必须经法定会议审议表决通过，标题下方须标注通过的时间和会议名称。
- 决议内容应高度概括，体现会议的集体意志。
- 与决定不同，决议强调的是"会议通过"的集体意思表示，而非单一机关的决策。
