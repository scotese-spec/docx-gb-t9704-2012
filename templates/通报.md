# 通报模板

## 适用场景
适用于表彰先进、批评错误、传达重要精神和告知重要情况。属下行文，兼具告知性与教育性。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号]

[主体]
[标题] 关于[事由]的通报
[主送机关]:
　　[开头段：概述通报的事由和目的]
　　[主送事项段：详述事实经过、原因分析、性质认定]
　　[处理/表彰决定段：明确处理结果或表彰方式]
　　[要求/号召段：提出希望、要求或经验教训]

[版记]
────────────────────────────
[发文机关（印章）]
[成文日期]
────────────────────────────
[抄送机关：×××，×××]
[印发机关]                        [印发日期]
```

## 常用句式
- 「[时间]，[地点]发生/出现×××[事项]。现将有关情况通报如下。」
- 「为表彰先进，激励[对象]，现决定对×××予以通报表彰。」
- 「×××的行为性质严重，影响恶劣。根据[规定]，决定给予×××通报批评。」
- 「希望各级各部门引以为戒，举一反三，切实防止类似问题再次发生。」
- 「现将[某项工作/活动的]情况予以通报。」

## 注意事项
- 表彰性通报应事实典型、评价恰当，发挥示范引领作用。
- 批评性通报应定性准确、措辞严谨，避免引发争议。
- 情况通报应客观全面，分析深入，为下级决策提供参考。
