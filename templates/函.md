# 函模板

## 适用场景
适用于不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。属平行文，分为发函和复函。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号]

[主体]
[标题] 关于[事由]的函
[主送机关]:
　　[开头段：说明发函的缘由、目的或依据]
　　[事项段：商洽/询问/请求的具体内容]
　　[结尾段：使用函专用结尾语]

[版记]
────────────────────────────
[发文机关（印章）]
[成文日期]
────────────────────────────
[抄送机关：×××，×××]
[印发机关]                        [印发日期]
```

## 常用句式
- 「根据[依据]，现就×××有关事宜函告如下。」
- 「为[目的]，拟于[时间]举行×次×××，诚邀贵单位派员参加。」
- 「以上意见，请即函复。」「盼予函复。」「专此函达。」
- 「贵单位《关于×××的函》（××函〔202×〕×号）收悉。经研究，现函复如下。」（复函专用）
- 「特此函告。」「特此函复。」

## 注意事项
- 函的语气应平等、诚恳、简明，不得使用命令式语言。
- 函的适用范围是不相隶属机关，有隶属关系时应使用请示或通知。
- 复函须引用来函文号，做到有问有答。
