# 公报模板

## 适用场景
适用于公布重要决定或重大事项。通常由党政高级机关或会议发布，面向全社会公开，具有高度的权威性和新闻性。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号（可选）]

[主体]
[标题] [会议名称]公报
（[××××年×月×日通过]）
[正文]：
　　[导语段：概述会议/事件基本情况]
　　一、[事项一：主要数据/核心内容]
　　二、[事项二：重大决定/重要判断]
　　三、[事项三：工作部署/远景规划]
　　[号召或结束语]

[签署/发布机关]
[成文日期]

[版记]
────────────────────────────
[印发机关]                        [印发日期]
```

## 常用句式
- 「[会议名称]于[时间]在[地点]举行。出席会议的有：[人员]。」
- 「全会听取和讨论了×××所作的工作报告，审议通过了《×××》。」
- 「[时间]国民经济和社会发展统计公报显示，全年实现地区生产总值×××亿元，比上年增长×%。」
- 「全会认为/全会强调/全会指出，×××是新时代坚持和发展中国特色社会主义的×××。」
- 「全会号召，全党全国各族人民要紧密团结在以×××同志为核心的党中央周围，为×××而奋斗。」

## 注意事项
- 公报语言应高度凝练、客观准确，以事实和决议为依据，不得夹带个人倾向。
- 联合公报须经各方协商一致，签署人代表各自机关。
- 新闻性公报应注重数据的可公布性和时效性。
