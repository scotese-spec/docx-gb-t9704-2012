# 通告模板

## 适用场景
适用于在一定范围内公布应当遵守或周知的事项。与公告相比，适用范围较窄、事项级别较低。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号（可选）]

[主体]
[标题] 关于[事由]的通告
[正文]：
　　[开头段：说明通告的目的、依据]
　　[事项段：分条列出需周知或遵守的事项]
　　一、[事项一]
　　二、[事项二]
　　三、[事项三]
　　[结尾段：执行要求或注意事项]
　　[落款]

[版记]
────────────────────────────
[发文机关（印章）]
[成文日期]
────────────────────────────
[印发机关]                        [印发日期]
```

## 常用句式
- 「为[目的]，根据[依据]，现通告如下。」
- 「自××××年×月×日起，在×××范围内，禁止/实行/执行以下措施。」
- 「违反本通告规定的，由×××部门依法予以处罚。」
- 「请广大[对象]自觉遵守，积极配合。」
- 「特此通告。」「本通告自发布之日起施行。」

## 注意事项
- 通告面向社会大众，语言应通俗易懂但保持公文庄重性。
- 涉及禁止、限制等约束性事项时，须有明确的法律法规依据。
- 通告发布后应在相关区域张贴或在适当范围内传播。
