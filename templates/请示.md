# 请示模板

## 适用场景
适用于向上级机关请求指示、批准。属上行文，须标注签发人，坚持一事一请、一文一事。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号]                                    签发人：[签发人姓名]

[主体]
[标题] 关于[事由]的请示
[主送机关]:
　　[开头段：说明请示的背景、依据和理由]
　　[请示事项段：明确具体的请求内容]
　　[必要性/可行性分析段：阐述提出请示的理由]
　　[结尾段：妥否，请批示。]

[版记]
────────────────────────────
[发文机关（印章）]
[成文日期]
（联系人：[姓名]　联系电话：[电话]）
────────────────────────────
[抄送机关：×××，×××]
[印发机关]                        [印发日期]
```

## 常用句式
- 「为[目的]，根据[依据]，现就×××事项请示如下。」
- 「该事项[背景]，拟采取以下方案：……」
- 「妥否，请批示。」（通用结尾）
- 「以上请示如无不妥，请批转各地区各部门执行。」
- 「经研究，现提出如下意见，请审示。」

## 注意事项
- 严格一事一请，一份请示只能有一个主送机关。
- 请示理由要充分，方案要具体，便于上级决策。
- 请示事项涉及其他部门职权时，应当先协商一致后再行请示。
- 不得越级请示，因特殊情况必须越级时，应同时抄送被越过的机关。
