# 命令（令）模板

## 适用场景
适用于公布行政法规和规章，宣布施行重大强制性措施，嘉奖有关单位和人员，批准授予和晋升衔级。属下行文，发文机关级别较高。

## 结构框架
```
[版头]
[发文机关文件头]
第×号（令号）

[主体]
[标题] [发文机关]令
（或：[发文机关]关于[事由]的命令）

　　[正文段：发布事项或强制措施内容]
　　[从某年某月某日起施行/自公布之日起施行]

[签署]
[发文机关职务署名]
[成文日期]

[版记]
────────────────────────────
[印发机关]                        [印发日期]
```

## 常用句式
- 「《×××》已经×××会议通过，现予公布，自××××年×月×日起施行。」
- 「为[目的]，现发布如下命令：一、……二、……三、……」
- 「任命×××为[职务]；免去×××的[职务]。此令。」
- 「授予×××同志"×××"荣誉称号。此令。」
- 「自本命令发布之日起实施。」

## 注意事项
- 命令（令）的发文机关级别较高，一般限于国家主席、国务院及部委、县级以上地方人民政府。
- 令号以一届政府或一年为周期依次编排。
- 公布行政法规和规章的命令必须附法规文本全文。
