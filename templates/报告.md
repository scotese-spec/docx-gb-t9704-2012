# 报告模板

## 适用场景
适用于向上级机关汇报工作、反映情况、答复上级机关询问。属上行文，须标注签发人。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号]                                    签发人：[签发人姓名]

[主体]
[标题] 关于[事由]的报告
[主送机关]:
　　[引言段：说明报告缘由]
　　[基本情况段：概述总体态势或工作背景]
　　[主体段一：主要做法与成效]
　　[主体段二：存在问题与不足]
　　[主体段三：下一步工作打算或意见建议]
　　[结尾段：专此报告]

[版记]
────────────────────────────
[发文机关（印章）]
[成文日期]
────────────────────────────
[抄送机关：×××，×××]
[印发机关]                        [印发日期]
```

## 常用句式
- 「根据[上级要求/文件依据]，现将×××情况报告如下。」
- 「截至目前，×××工作总体进展顺利/基本完成任务/存在以下问题。」
- 「主要做法是：一是……二是……三是……」
- 「存在的问题主要表现在以下几个方面：……」
- 「下一步，我们将重点抓好以下工作：……专此报告。」

## 注意事项
- 报告中不得夹带请示事项，如需请示应另行行文。
- 情况报告应客观真实，数据准确，分析深入。
- 答复上级询问的报告应有明确的针对性，逐条回应。
