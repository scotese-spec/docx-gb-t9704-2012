# 决定模板

## 适用场景
适用于对重要事项作出决策和部署，奖惩有关单位和人员，变更或撤销下级机关不适当的决定事项。

## 结构框架
```
[版头]
[发文机关文件头]
[发文字号]

[主体]
[标题] 关于[事由]的决定
[主送机关]（公开发布的可省略）:
　　[开头段：说明决定的背景、依据和目的]
　　[决定事项段：分条列出决定的具体内容]
　　一、[事项一]
　　二、[事项二]
　　三、[事项三]
　　[执行要求段：提出贯彻落实的具体要求]
　　[结尾段：本决定自发布之日起施行]

[版记]
────────────────────────────
[发文机关（印章）]
[成文日期]
────────────────────────────
[抄送机关：×××，×××]
[印发机关]                        [印发日期]
```

## 常用句式
- 「根据[依据]，经[会议/上级]研究，作出如下决定。」
- 「×××同志在×××工作中表现突出/犯有严重错误，决定给予×××[奖励/处分]。」
- 「会议审议通过了《×××方案》，决定自即日起实施。」
- 「决定撤销×××作出的×××决定。」
- 「各级各部门要认真贯彻本决定精神，确保各项任务落实到位。」

## 注意事项
- 奖惩类决定应事实清楚、依据充分、定性准确。
- 变更或撤销下级决定时，应说明理由和法律依据。
- 部署性决定的事项应有明确的时间表、路线图和责任分工。
