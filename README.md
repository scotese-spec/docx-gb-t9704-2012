## 这玩意儿是干什么的

写公文有两难：

- **不知道写啥**——请示？报告？通知？函？傻傻分不清
- **知道写啥，不会排版**——发文字号格式，签发人字体，版记横线粗细……国标写了七十页，没人想看

这个项目解决这两个问题。把 `SKILL.md` 加载给 AI 之后：

1. 你用大白话描述情况
2. AI 判断文种、追问缺失信息
3. 输出格式符合 GB/T 9704-2012 的完整 `.docx`，打开即用

---

## 怎么用

### 方式一：GitHub Copilot Agent（最省心）

`SKILL.md` 放到 `~/.agents/skills/docx-gb-t9704-2012/` 目录下，Copilot 识别到触发词（通知/请示/公文……）自动加载，直接生成 `.docx` 文件，全程不用离开 VS Code。

### 方式二：国内网页 AI（无需安装任何东西）

把 `SKILL.md` 的内容喂给 AI，它就能写公文。支持以下平台：

| 平台 | 地址 | 怎么喂 |
|------|------|--------|
| **DeepSeek** | chat.deepseek.com | 对话框左下角📎上传文件，或全选复制粘贴 |
| **豆包** | doubao.com | 点击📎附件上传，或复制粘贴 |
| **Kimi** | kimi.moonshot.cn | 直接拖文件进对话框，长文本支持最好 |
| **通义千问** | tongyi.aliyun.com | 点击📎上传文件 |
| **文心一言** | yiyan.baidu.com | 复制粘贴（文件上传不稳定） |
| **讯飞星火** | xinghuo.xfyun.cn | 复制粘贴 |

**通用步骤：**

1. 新建对话
2. 上传 `SKILL.md` 文件，**或**打开文件全选（Ctrl+A）→ 复制 → 粘贴到对话框发送
3. 等 AI 回复确认后，直接说你的需求，例如：

   > 帮我写一份通知，发文机关是XX局，要求各部门6月底前完成安全自查

4. AI 会追问缺失信息，回答完就能拿到完整公文正文

> ⚠️ 网页 AI 只能输出**公文文字内容**，无法直接生成 `.docx` 文件。
> 拿到正文后，自己复制到 Word/WPS 里，参照下方排版规格手动调格式；
> 或者用方式一（VS Code Copilot Agent）全自动生成排好版的 `.docx`。

## 说两句话就能出稿

不用背格式，不用查规范，这样开口就行：

| 你的情况 | 你可以说 |
|----------|---------|
| 知道文种和事由 | `写一份请示，申请采购办公设备2万元` |
| 知道情况，不确定文种 | `我要向上级汇报上半年工作，写什么合适？` |
| 完全两眼一抹黑 | `我需要写个公文但不知道写啥类型` |
| 领导催得急 | `帮我写个通知，让各部门5月底前报安全自查情况` |

AI 会主动来问你发文机关、主送机关、发文字号这些——**它不问的，你也不用操心**。

## 排版规格（它记着，你不用记）

| 要素 | 规格 |
|------|------|
| 纸张 | A4，210×297mm |
| 页边距 | 上3.7 / 下3.5 / 左2.8 / 右2.6 cm |
| 行距 | 固定值28磅，每面22行×28字 |
| 标题 | 2号小标宋体，居中 |
| 正文 | 3号仿宋，首行缩进2字 |
| 签发人 | "签发人："仿宋 + 姓名**楷体**（国标7.2.6，很多人弄错） |
| 页码 | `— 1 —` 格式，单页右空一字，双页左空一字 |
| 版记 | 抄送细线、印发粗线，顺序不能乱 |

## 依据标准

- **GB/T 9704-2012** 党政机关公文格式
- **GB/T 15834** 标点符号用法
- **GB/T 15835** 出版物上数字用法
- **中办发〔2012〕14号** 党政机关公文处理工作条例
