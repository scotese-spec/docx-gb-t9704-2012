## 这玩意儿是干什么的

写公文有两难：

- **不知道写啥**——请示？报告？通知？函？傻傻分不清
- **知道写啥，不会排版**——发文字号格式，签发人字体，版记横线粗细……国标写了七十页，没人想看

这个项目解决这两个问题。把 `SKILL.md` 加载给 AI 之后：

1. 你用大白话描述情况
2. AI 判断文种、追问缺失信息
3. 输出格式符合 GB/T 9704-2012 的完整 `.docx`，打开即用

---

## 怎么用

### 方式一：GitHub Copilot Agent（最省心）

`SKILL.md` 放到 `~/.agents/skills/docx-gb-t9704-2012/` 目录下，Copilot 识别到触发词（通知/请示/公文……）自动加载，直接生成 `.docx` 文件，全程不用离开 VS Code。

### 方式二：网页 AI（DeepSeek / Claude / ChatGPT 等）

1. 打开 `SKILL.md`，**全选复制**
2. 粘贴到对话开头发送（或直接上传文件）
3. 然后说你的需求

> ⚠️ 网页 AI 没法帮你跑 Python，只能输出公文正文。
> 要自动生成排好版的 `.docx`，用方式一。

## 说两句话就能出稿

不用背格式，不用查规范，这样开口就行：

| 你的情况 | 你可以说 |
|----------|---------|
| 知道文种和事由 | `写一份请示，申请采购办公设备2万元` |
| 知道情况，不确定文种 | `我要向上级汇报上半年工作，写什么合适？` |
| 完全两眼一抹黑 | `我需要写个公文但不知道写啥类型` |
| 领导催得急 | `帮我写个通知，让各部门5月底前报安全自查情况` |

AI 会主动来问你发文机关、主送机关、发文字号这些——**它不问的，你也不用操心**。

## 排版规格（它记着，你不用记）

| 要素 | 规格 |
|------|------|
| 纸张 | A4，210×297mm |
| 页边距 | 上3.7 / 下3.5 / 左2.8 / 右2.6 cm |
| 行距 | 固定值28磅，每面22行×28字 |
| 标题 | 2号小标宋体，居中 |
| 正文 | 3号仿宋，首行缩进2字 |
| 签发人 | "签发人："仿宋 + 姓名**楷体**（国标7.2.6，很多人弄错） |
| 页码 | `— 1 —` 格式，单页右空一字，双页左空一字 |
| 版记 | 抄送细线、印发粗线，顺序不能乱 |

## 快速开始

### 第一步：加载技能

将 `SKILL.md` 的全部内容粘贴到你的 AI 平台系统提示或对话开头。

**支持平台**：OpenCode · Claude Code · Cursor · GitHub Copilot Agent · 任何支持自定义系统提示的 AI 工具

### 第二步：告诉 AI 你的情况

三种开口方式都行：

| 你不确定的程度 | 你可以说 |
|------------|---------|
| 知道文种和事由 | "写一份**请示**，申请采购办公设备2万元" |
| 知道情况，不确定文种 | "我要向上级汇报上半年工作，写什么？" |
| 完全不知道从哪里开始 | "我需要写一份公文，但不知道写什么类型" |

### 第三步：和 AI 对话完善

AI 会：
1. 帮你确认文种（不知道它来问）
2. 逐一询问缺失信息（一次一个问题，不轰炸）
3. 生成草稿并在聊天中显示文本预览
4. 根据你的反馈修改，直到你满意

### 第四步：拿走成品

确认无误后，AI 输出排版完整的 `.docx`，Word / WPS 打开即用。
如果环境缺少 `python-docx`，自动降级为结构化 Markdown，复制到 Word 后按提示设置格式。

## 这是什么

一个单文件 AI 技能（`SKILL.md`）。加载后 AI 掌握：

- **15 种公文**的写作框架、铁律和常用句式
- **GB/T 9704-2012** 完整排版规范（版头版记页码字体字号页边距）
- **对话引导流程**（帮不知道从哪里开始的用户一步步完成公文）
- **修改请求映射**（"太正式了"→软化语气，"加一个附件"→自动追加，等14种口语操作）
- **格式自检修复**（自动检测并修正页边距、英文标点、首行缩进）
- **python-docx 完整代码**（含所有国标细节，可直接运行）
